# リフォームヤマキシ トップページ リニューアル 一式

メインカラー `#fe3301`　／　最優先の目標：**LINEでの相談・見積依頼**
想定するお客様：**子育て世代〜70代**・石川県／福井県（各店からおよそ30分以内）

---

## 1. フォルダ構成

ページごとにフォルダを分ける前提で作ってあります。

```
yamakishi-site/
├── index.html                トップページ
│
├── assets/                   全ページで共有するファイル
│   ├── css/
│   │   ├── common.css        全ページ共通（色・文字・ヘッダー・フッター・ボタン）
│   │   ├── home.css          トップページ専用
│   │   └── page.css          下層ページ共通（パンくず・見出し・本文・一覧カード）
│   ├── js/
│   │   ├── common.js         全ページ共通（メニュー・追従CTA・スクロール演出・計測）
│   │   └── home.js           トップページ専用（スライダー・見積りシミュレーターなど）
│   └── img/
│       ├── logo/             ロゴ
│       ├── character/        キャラクター（PNG＋WebP／16点）
│       └── common/           メインビジュアル等をここに置いてください
│
├── products/  index.html     ← 下層ページのテンプレート（この形を複製して増やします）
├── works/     voice/     shops/    area/
├── flow/      faq/       news/     inquiry/     company/
│
└── wp/                       WordPress用
    ├── header.php            共通ヘッダー
    ├── footer.php            共通フッター
    ├── front-page.php        トップページ（お知らせ・施工事例・声をループで出力）
    └── functions-snippet.php functions.php に追記するコード
```

**CSSの読み込み順**

| ページ | 読み込むCSS | 読み込むJS |
|---|---|---|
| トップ | common.css → home.css | common.js → home.js |
| 下層 | common.css → page.css | common.js |

**ページを増やすとき**は `products/index.html` を複製し、
`../assets/…` の相対パスの深さだけ合わせてください（2階層下なら `../../assets/…`）。

## 2. JavaScriptで動く部分

すべてバニラJS（jQueryなどのライブラリ不要）です。動作は実機で確認済みです。

**common.js（全ページ）**

| 機能 | 内容 |
|---|---|
| ヘッダー | スクロールすると影がつく。高さを自動計測してアンカーのズレを防ぐ |
| ドロワーメニュー | スマホの右上MENUから。Escキー・背景タップで閉じる。フォーカスも閉じ込め |
| 追従CTA | ファーストビューを過ぎたら下からせり上がり、フッター手前で引っ込む |
| ページトップ | 600pxスクロールで出現 |
| スクロール演出 | `data-reveal` の要素がふわっと表示（`data-reveal-delay` で時間差） |
| スムーススクロール | ヘッダーの高さを引いた位置に止まる |
| **計測イベント** | LINE・電話・来店予約のクリックを `dataLayer` と `gtag` に送信 |

**home.js（トップページ）**

| 機能 | 内容 |
|---|---|
| 見出しの文字送り | h1が1文字ずつ出てくる |
| メインビジュアル | 5秒ごとの自動フェード切替＋ドット＋スワイプ。マウスを乗せると停止 |
| 数字のカウントアップ | 実績バーの「10店舗」「約50年」などが0から回る |
| **Before/After比較** | つまみを左右に動かすと施工前後が入れ替わる。初回だけ自動で少し動いて操作を促す。キーボード（←→）でも操作可 |
| よくある質問 | 高さをなめらかに開閉するアコーディオン |
| 店舗タブ | 石川県／福井県の切り替え |
| **かんたん見積りシミュレーター** | 3つ選ぶだけで概算が出て、そのままLINEへ。入力欄なしなので離脱しにくい |

> シミュレーターの金額は `assets/js/home.js` の冒頭 `PRICE` と `AGE_FACTOR` にまとまっています。
> **必ず御社の実データに書き換えてください。** 現在の数値は一般的な相場を置いた仮の値です。

**動きが苦手な方への配慮**：OSの「視差効果を減らす」設定がオンの端末では、
アニメーションを自動的に止めます（`prefers-reduced-motion` 対応）。

## 3. お客様に合わせた設計（子育て世代〜70代）

- **本文17px・行間1.9** … 一般的なサイトより一回り大きくしています
- **ボタンは高さ60px以上** … 指でも押しやすく、押し間違いが起きにくい大きさ
- **むずかしいカタカナを減らす** … 「ユニットバス」→「お風呂」、「エリア」→「地域」など
- **電話番号を大きく** … 電話で相談したい年代のために、ヘッダー・最終CTA・フッターに大きく配置
- **キーボードだけでも操作できる** … フォーカス枠を太く表示、スキップリンクあり
- **色のコントラスト** … 文字に使うオレンジは濃い `#c92800`、塗りは `#fe3301` と使い分け

「30分以内で伺えます」というメッセージを、実績バー・選ばれる理由・店舗セクションの
3か所に入れています。近さは、この年代にいちばん効く安心材料です。

## 4. キャラクターの使い方

**出しすぎると効果が薄れる**ので、意味のある3か所だけに絞っています。
ほかの場所はシンプルな線アイコンで統一し、キャラクターが出てきたときに
「お、いた」と目に留まるようにしました。

### トップページ（3か所）

| 場所 | ファイル | ねらい |
|---|---|---|
| ヒーロー右下 | `char-hello` | 第一印象。ふきだし「相談だけでも大丈夫！」とセットで、問い合わせのハードルを下げます |
| 店舗・対応エリア | `char-truck` | 「お近くのお店からおよそ30分以内」という文と並べて、すぐ来てくれる感じを伝えます |
| 最終CTA | `char-stand`（ヘルメット姿で正面立ち） | 最後のひと押し。人の気配があるとボタンが押されやすくなります |

### 下層ページ（1ページ1か所まで）

`products/index.html` ではページ下部のCTAに `char-tel` を1点だけ。
この「1ページ1体まで」を目安に運用すると、うるさくなりません。

### 使っていない13点について

削除せず `assets/img/character/` にすべて残してあります。用途に合うものを、
下層ページを作るときに1点ずつ足していく想定です。

- `char-wrench`（スパナ）→ 修理・小工事ページ
- `char-roller` `char-paint-wall` `char-paint-walk`（塗装）→ 外壁塗装ページ
- `char-hammer`（ハンマー）→ 施工体制ページ
- `char-search`（虫めがね）→ 現地調査・リフォームの流れページ
- `char-anshin`（安心）→ 保証ページ
- `char-otoku`（お得）→ 補助金・キャンペーンページ
- `char-hinshitsu`（品質）→ こだわり・特徴ページ
- `char-peek`（のぞきこみ）→ フッターやセクションの角に少しだけ
- `char-bow` `char-run` `char-hello` → 汎用

CSSには `.p-pagehead__chara` と `.p-footer__chara` という置き場所を用意してあるので、
`<img>` を1行足すだけで配置できます。

### 画像について

各画像は透明部分を切り詰めて最大640pxに統一し、**WebP版も生成済み**です（1点15〜35KB）。
HTMLでは軽いWebPを読み込んでいます。古いブラウザも対象にする場合は `<picture>` で
PNGをフォールバックにしてください。

## 5. 公開前に差し替えが必要なもの

### ① パック価格の金額（`●●万円`）
`index.html` の 6商品ぶん。**ここが今回いちばん効く箇所です。**
リフォームサイトの離脱理由の大半は「金額が分からない」ことなので、
最低価格でかまいませんから必ず実数を入れてください。
あわせて `assets/js/home.js` の `PRICE` も実データに。

### ② 写真
`［メインビジュアル］` `［写真］〜` `BEFORE 写真` `AFTER 写真` の部分です。
HTMLにコメントアウトした `<img>` の見本を置いてあります。実装時は必ず
`width` `height` `alt` を入れ、メインビジュアルだけ `fetchpriority="high"`、
それ以外は `loading="lazy"` にしてください。表示速度の評価に直結します。

### ③ お客様の声の本文
`［お客様アンケートの実際のコメントを掲載］` の部分。
アンケート用紙の文面をそのまま載せるのがいちばん効きます。
手書きアンケートの写真を添えると、さらに信頼感が上がります。

### ④ ロゴ・ファビコン（Googleドライブから）
このzipには**画像本体を入れていません**。Googleドライブの
`yamakishi-site/assets/img/logo/` と `yamakishi-site/assets/img/favicon/` に
本物を配置済みなので、そちらからコピーしてください。

- ロゴ … `logo01.png`（横型 850×300／ヘッダーで使用）、`logo02.png`（縦型／予備）
- ファビコン … `favicon.ico` `icon-16x16.png` `icon-32x32.png`
  `apple-touch-icon-180x180.png` `icon-192x192.png` `icon-512x512.png`
  `site-tile-150x150.png` `manifest.json`
- `favicon.ico` は**サイトのルート**（`/favicon.ico`）にも置いてください

### ⑤ OGP画像
`assets/img/common/ogp.jpg`（1200×630px）を用意してください。
SNSやLINEでシェアされたときに出る画像です。

## 6. 計測の設定（必ず入れてください）

これがないと、リニューアルの効果が測れません。
JSからイベントは自動で送っているので、GA4側で受け取る設定をするだけです。

| イベント名 | 発火するタイミング |
|---|---|
| `line_click` | LINEボタンのクリック |
| `tel_click` | 電話番号のタップ |
| `reserve_click` | 来店予約ページへの遷移 |
| `contact_click` | お問い合わせページへの遷移 |
| `simulator_complete` | 見積りシミュレーターの完了 |

各イベントには `cta_position`（hero／header／fixed／simulator など）が付くので、
**どのボタンが効いているか**まで分かります。GA4の管理画面でこの5つを
「キーイベント（コンバージョン）」に設定してください。

## 7. WordPressへの組み込み

### 動的にする3か所（`wp/front-page.php` の ★1〜★3）

- ★1 施工事例 … カスタム投稿タイプ `works`
- ★2 お客様の声 … カスタム投稿タイプ `voice`
- ★3 お知らせ … 通常の投稿 `post`（追加設定なしでそのまま使えます）

### 手順

1. **子テーマ**を用意する
2. `assets/` フォルダをまるごと子テーマ直下にコピー
3. `wp/functions-snippet.php` の中身を `functions.php` の末尾に追記
4. `wp/header.php` `wp/footer.php` `wp/front-page.php` を子テーマ直下に置く
5. `index.html` の中身を `front-page.php` に移し、★1〜★3 を `wp/front-page.php` の
   該当ブロックに差し替える
6. 管理画面 › 設定 › パーマリンク で「変更を保存」（URLルールの更新）

### 画像パスの書き換え

```
index.html   src="assets/img/character/char-hello.webp"
　　↓
PHP          src="<?php echo esc_url( get_stylesheet_directory_uri() ); ?>/assets/img/character/char-hello.webp"
```

### 注意

- すでに `works` / `voice` を別の名前で運用中なら、`WP_Query` の `post_type` を合わせてください
- Yoast SEO などで構造化データを出している場合、JSON-LDが重複しないようどちらかに寄せてください
- CSS/JSは `functions.php` から読み込む形にしてあります（`<link>` の直書きは不要です）

## 9. 次に効く一手

トップページだけでセッション数が大きく増えることは、あまりありません。
効果が大きい順に挙げます。

1. **市町別ページ**（`/area/kanazawa/` など10市町ぶん）
   その市の施工事例と最寄り店舗を載せるだけで、「金沢市 リフォーム」等に強くなります。
   お店から30分以内、という御社の強みがそのまま活きるページです。
2. **施工事例の量産**
   1件ずつが「◯◯市 キッチンリフォーム 費用」の受け皿になります。金額と工期は必ず公開を。
3. **お困りごと記事**
   「給湯器 お湯が出ない 石川」「補助金 いつまで」など、検索されている困りごとに
   記事で答え、記事の最後からLINEへ誘導します。
