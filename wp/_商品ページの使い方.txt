================================================================
商品ページの作り方（WordPress）
リフォームヤマキシ
================================================================

キッチン・お風呂・トイレ・洗面化粧台など、
商品ページはすべて「商品」メニューから作れます。

デザインやレイアウトは自動です。
入力する人は、欄を埋めて写真を選ぶだけで大丈夫です。


────────────────────────────────────────────────
■ ファイルの置き場所
────────────────────────────────────────────────

wp-content/themes/ymkrf-child/
  ├ functions.php                     ← 下の1行を追記
  ├ inc/functions-product.php         ← 商品の機能
  ├ single-ymkrf_product.php          ← 商品ページの見た目
  └ assets/css/product.css            ← 商品ページ専用のCSS

functions.php に追記する1行：

  require_once get_stylesheet_directory() . '/inc/functions-product.php';

置いたあと、管理画面の「設定 → パーマリンク」を一度開いて
「変更を保存」を押してください（URLの設定が更新されます）。


────────────────────────────────────────────────
■ 最初に1回だけやる準備
────────────────────────────────────────────────

□ 商品 → 商品カテゴリ に、次を登録
     キッチン       （スラッグ: kitchen）
     お風呂         （スラッグ: bathroom）
     トイレ         （スラッグ: toilet）
     洗面化粧台     （スラッグ: lavatory）
     給湯器・エコキュート（スラッグ: boiler）
     外壁・屋根     （スラッグ: outer-wall）

□ 商品 → メーカー に、扱うメーカーを登録
     Panasonic / LIXIL / TOTO / クリナップ / タカラスタンダード など

□ 商品 → 展示店舗 に、10店舗を登録
     スラッグは店舗ページのURLに合わせてください
     例：金沢野々市店 → nonoichi

※スラッグ＝URLに使う英字。商品カテゴリのスラッグは
　そのまま /products/kitchen/ のようなURLになります。


────────────────────────────────────────────────
■ 商品を1つ登録する
────────────────────────────────────────────────

【いちばん早いのは「複製」です】

商品一覧で、似た商品の名前にマウスを乗せると
「複製して新規作成」というリンクが出ます。

これを使うと、標準工事内容・標準仕様・カラーなどが
そのままコピーされるので、違うところだけ直せば済みます。
1から入力するより、はるかに早く終わります。


【1から作る場合】

1. 商品 → 新しい商品

2. いちばん上のタイトル欄に商品名を入れる
   （例：V-style（Vスタイル））

3. 「商品データ（基本）」の欄を埋める
   ・キャッチコピー、グレード、型（サイズ）
   ・標準工事費、商品代　← 数字だけ。込み価格は自動計算
   ・工期（日数）
   ・特徴 1〜3
   ・写真の注意書き

4. 画面の右側で
   ・アイキャッチ画像 … いちばん大きく出る商品写真
   ・商品カテゴリ … キッチンなど（★必ず1つ選ぶ）
   ・メーカー
   ・展示店舗 … 置いてあるお店にチェック

5. 下に並んでいる欄を、必要なぶんだけ埋める
   ・組み合わせイメージ写真
   ・扉カラー
   ・取っ手
   ・標準仕様
   ・おすすめポイント
   ・おすすめオプション
   ・ヤマキシ標準工事内容

   「＋ 行を追加」で行が増えます。
   左端の ≡ をドラッグすると順番を変えられます。
   × で行を消せます。

6. 公開


────────────────────────────────────────────────
■ 空欄にしておくと、その部分は出ません
────────────────────────────────────────────────

たとえばトイレには「取っ手」がありません。
その場合は「取っ手」の欄を空のままにしてください。
見出しごと表示されなくなります。

無理に埋める必要はありません。


────────────────────────────────────────────────
■ 入力しなくていいもの（自動で出ます）
────────────────────────────────────────────────

・込み価格
     標準工事費 ＋ 商品代 を自動計算します

・グレードUP → ／ ← グレードを戻す
     同じカテゴリの商品を「込み価格の安い順」に並べて、
     ひとつ上とひとつ下を自動で表示します。
     いちばん安い商品では「戻す」が、
     いちばん高い商品では「UP」が、自動で消えます。

・施工事例
     施工事例の「部位」が商品カテゴリと同じものを3件、
     自動で表示します。
     ※施工事例側の「部位」に、商品カテゴリと同じスラッグ
     　（kitchen など）を作っておいてください。

・パンくず、構造化データ、お問い合わせボタン


────────────────────────────────────────────────
■ おすすめポイントの「グループ」について
────────────────────────────────────────────────

ひとつの見出しの下に Point 1、Point 2 と並べたい場合があります。
（例：「フロアストッカー」の中に2つのポイント）

そのときは、2行目以降の
　「グループ小見出し」「グループ見出し」を空欄
にしてください。ひとつ上の行と同じまとまりになります。

  1行目： グループ小見出し=収納力抜群
          グループ見出し  =「フロアストッカー」
          見出し          = 大割のスライド収納        → Point 1

  2行目： グループ小見出し=（空欄）
          グループ見出し  =（空欄）
          見出し          = 内引出し付き調理キャビネット → Point 2

  3行目： グループ小見出し=快適性がアップ
          グループ見出し  =「静音ステンレスシンク」
          見出し          = 水ハネ音などを抑えられます  → 新しいまとまりの Point 1


────────────────────────────────────────────────
■ 写真について
────────────────────────────────────────────────

写真の加工（余白を切る、線を消す、大きさを揃える）は
手間がかかるので、Claude側で用意します。
加工済みのものをメディアに登録して、選ぶだけにしてください。

メディアに上げるとき、ファイル名は英数字にしてください。
（日本語のファイル名はサーバーによって不具合が出ます）


────────────────────────────────────────────────
■ 項目を増やしたくなったら
────────────────────────────────────────────────

inc/functions-product.php の

  「2. 入力欄の定義　★項目を増やすときはここ」

だけを直せば、入力画面に欄が増えます。
ただし、その内容をページに表示するには
single-ymkrf_product.php にも追記が必要です。

自分で触らず、Claudeに依頼していただくのが安全です。
