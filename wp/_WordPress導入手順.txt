================================================================
WordPress 導入手順
リフォームヤマキシ（reform専用サイト）
2026年8月6日
================================================================

サーバーには他のサイトが同居しています。
名前がぶつかると、別サイトのデータが混ざる・消えるといった
取り返しのつかない事故になります。

そこで、このサイトに関するものは
すべて  ymkrf  （YaMaKishi ReForm）で始めます。
（データベース名だけは reform_yamakishi。サーバーの一覧で
　いちばん目に付く名前なので、より分かりやすくしています）
一目で「リフォームサイトのもの」と分かるようにするためです。

────────────────────────────────────────────────
■ 0. まず用意するもの
────────────────────────────────────────────────

□ ドメイン        yamakishi-reform.jp
□ SSL証明書       無料のもので十分（Let's Encrypt）
□ サーバーの管理画面のログイン情報
□ FTP（またはファイルマネージャー）のログイン情報

【サーバーの条件】WordPress公式の推奨は次の通りです。
契約前に必ず確認してください。

  PHP        8.3 以上
  データベース MySQL 8.0 以上 ／ MariaDB 10.11 以上
  HTTPS      必須

これより古くても動きますが、サポートが切れていて
セキュリティ上の危険があります。選べるなら推奨版にしてください。


────────────────────────────────────────────────
■ 1. ★ 名前を先に決める（いちばん重要）
────────────────────────────────────────────────

作業を始める前に、この表を印刷するか手元に置いてください。
入力を求められたら、この通りに打ちます。

┌──────────────────┬────────────────────────────┐
│ 何の名前            │ 決めた名前                  │
├──────────────────┼────────────────────────────┤
│ データベース名      │ reform_yamakishi            │
│ データベースユーザー│ ymkrf_wpuser                │
│ データベースパスワード│ （自動生成の強いものを保存）│
│ テーブル接頭辞      │ ymkrf_        ★最重要       │
│ 公開フォルダ        │ .../yamakishi-reform.jp/    │
│                     │        public_html/         │
│ 親テーマ            │ ymkrf                       │
│ 子テーマ            │ ymkrf-child                 │
│ 管理者ユーザー名    │ ymkrf-admin （adminは禁止） │
└──────────────────┴────────────────────────────┘

【テーブル接頭辞とは】
WordPressを入れる途中で「テーブル接頭辞」という欄が出ます。
初期値は必ず  wp_  になっています。

    ここを  ymkrf_  に変えてください。

wp_ のままだと、同じデータベースに別のサイトを入れたとき
テーブル名がぶつかって、両方のデータが混ざります。
あとから変えるのは危険なので、最初に必ず変えてください。

【できればデータベースは分ける】
接頭辞を分けるより、サイトごとに別のデータベースを作る方が
はるかに安全です。作れるなら reform_yamakishi を単独で用意してください。


────────────────────────────────────────────────
■ 2. データベースを作る
────────────────────────────────────────────────

サーバーの管理画面 →「データベース」または「MySQL設定」

 1. 新しいデータベースを作る
       名前　　　　  reform_yamakishi
       文字コード　  utf8mb4（選べる場合）

 2. 新しいユーザーを作る
       名前　　　　  ymkrf_wpuser
       パスワード　  自動生成の強いもの

 3. 作ったユーザーに、reform_yamakishi への権限を与える

 4. 次の4つをメモしておく（次の手順で使います）
       ・データベース名
       ・ユーザー名
       ・パスワード
       ・ホスト名（多くは localhost。管理画面に書いてあります）

※メモはパスワード管理ソフトか、鍵のかかる場所へ。
　メールやチャットに貼らないでください。


────────────────────────────────────────────────
■ 3. WordPressを入れる
────────────────────────────────────────────────

多くのレンタルサーバーに「WordPress簡単インストール」が
あります。それを使うのが安全で早いです。

【簡単インストールを使う場合】

  ドメイン　　　  yamakishi-reform.jp
  インストール先  空欄（ドメイン直下）
  サイト名　　　  リフォームヤマキシ
  ユーザー名　　  ymkrf-admin
  パスワード　　  自動生成のもの
  メールアドレス  受け取れるアドレス
  データベース　  「自分で作ったものを使う」を選び、
                  手順2でメモした4つを入力
  テーブル接頭辞  ymkrf_       ★ここを必ず変える

  ※接頭辞を変えられない簡単インストールもあります。
  　その場合は下の「手動で入れる場合」にしてください。

【手動で入れる場合】

 1. ja.wordpress.org から最新版をダウンロード
 2. 解凍して、中身を public_html/ にアップロード
    （wordpress フォルダごとではなく、中身だけ）
 3. ブラウザで https://yamakishi-reform.jp/ を開く
 4. 画面に従って、手順2でメモした4つを入力
 5. 「テーブル接頭辞」を  ymkrf_  に変更
 6. サイト名・ユーザー名（ymkrf-admin）・パスワードを設定


────────────────────────────────────────────────
■ 4. 入れた直後にやること（順番通りに）
────────────────────────────────────────────────

□ 設定 → 一般
     ・WordPressアドレス と サイトアドレス が
       https:// で始まっているか確認
     ・違えば https:// に直す

□ 設定 → 表示設定
     ・「検索エンジンがサイトをインデックスしないようにする」に
       チェックを入れる
     ★公開の日まではチェックを入れたまま。
     　公開時に外すのを忘れないでください。

□ 設定 → パーマリンク
     ・「投稿名」を選んで保存
     ・商品ページのURLがこの設定で決まります

□ プラグイン
     ・Hello Dolly を削除
     ・TypeSquare など、使わないものを削除

□ 投稿・固定ページ
     ・「Hello world!」「サンプルページ」を削除

□ ユーザー
     ・admin という名前のユーザーがいたら削除
       （世界中のボットが admin を狙っています）


────────────────────────────────────────────────
■ 5. セキュリティ（必ずやってください）
────────────────────────────────────────────────

8月4日に、実際にボット攻撃でサイトが落ちています。
WordPressを立てると、この手の攻撃は確実に増えます。

□ SiteGuard WP Plugin を入れる（無料）
     ・管理画面のURLを /wp-admin/ から変更
     ・ログイン画面に画像認証を追加
     ・ログイン失敗が続くIPを遮断
     ※新しいログインURLは必ず控えてください。
     　忘れると自分が入れなくなります。

□ 自動バックアップを設定
     ・サーバーの機能があればそれを使う
     ・無ければ UpdraftPlus（無料）
     ・保存先はサーバーの外（Googleドライブなど）

□ 管理者は必要な人だけ
     ・更新するだけの人は「編集者」権限で十分です


────────────────────────────────────────────────
■ 6. テーマとファイルを置く
────────────────────────────────────────────────

wp-content/themes/ の中に、こう置きます。

  ymkrf/           ← 親テーマ
  ymkrf-child/     ← 子テーマ（★作業はここだけ）
    ├ style.css
    ├ functions.php
    ├ header.php
    ├ footer.php
    ├ front-page.php
    ├ single-ymkrf_product.php
    ├ inc/
    │   ├ functions-snippet.php
    │   └ functions-product.php
    └ assets/
        ├ css/   common.css / home.css / page.css / product.css / lp.css
        ├ js/    common.js / home.js
        └ img/   logo / favicon / character / products …

【なぜ子テーマか】
親テーマを直接いじると、テーマを更新するたびに
変更が全部消えます。必ず子テーマ側で作業してください。

【functions.php に書く2行】

  require_once get_stylesheet_directory() . '/inc/functions-snippet.php';
  require_once get_stylesheet_directory() . '/inc/functions-product.php';

【置いたあと】
  外観 → テーマ で ymkrf-child を有効化
  設定 → パーマリンク を開いて「変更を保存」を1回押す
  （URLの設定を更新するために必要です）


────────────────────────────────────────────────
■ 7. 中身を入れる
────────────────────────────────────────────────

 1. 商品 → 商品カテゴリ に、キッチン／お風呂／トイレ／
    洗面化粧台 …を登録（スラッグは kitchen などの英字）
 2. 商品 → メーカー、展示店舗 を登録
 3. 商品を1件登録して、表示を確認
 4. Contact Form 7 を入れて、来店予約フォームを作る
    → wp/contact-form-7_webrsv.txt の通りに設定

くわしくは  wp/_商品ページの使い方.txt  を見てください。


────────────────────────────────────────────────
■ 8. 公開するとき
────────────────────────────────────────────────

□ 設定 → 表示設定 の「検索エンジン…」のチェックを外す
     ★これを忘れると、いつまでもGoogleに載りません
□ 全ページの表示をスマホで確認
□ フォームの送信テスト（自分宛に届くか）
□ 旧サイトからのリダイレクト設定
     ・旧URL → 新URL の対応表を作って、301リダイレクト
     ・これをやらないと、今までの検索順位を失います
□ Googleサーチコンソールにサイトマップを送信
